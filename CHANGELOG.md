# Histórico de versões

## Melhorias em validação para a próxima versão (ainda não lançada)

- Gravação transacional: só atualiza as tarefas após salvamento bem-sucedido no navegador.
- Proteção de dados locais ilegíveis e exportação de cópia bruta para recuperação.
- Orientação inicial no quadro vazio e indicação da rolagem horizontal no celular.
- Plano de testes de usabilidade, coleta de feedback voluntário e roteiro de divulgação.
- Novos testes de regressão automatizados.

## Atualizações após v1.0.0

- URLs corrigidos após renomear o repositório para `kanban-flow`.
- Metadados para pré-visualização e URL canônica no site.
- Proteção contra perda do quadro quando o navegador bloqueia salvamento ao importar ou limpar.
- Testes automatizados de validação dos dados, links e scripts.
- Arquivos básicos para mecanismos de busca (`robots.txt` e `sitemap.xml`).
- Chave local de dados `kanban_flow_public_v1` preservada.

## v1.0.0

- Primeira versão pública do Kanban Flow.
