# Plano de validação — Kanban Flow

**Objetivo:** confirmar que profissionais autônomos, freelancers e pequenos negócios conseguem concluir os fluxos essenciais no celular e no computador, antes do lançamento v1.1.0.

## Participantes

Convide 5 a 10 pessoas, preferencialmente 3 no celular e 2 no computador como cobertura mínima. A participação é voluntária. Não solicite dados reais de clientes, nomes de terceiros, senhas, contratos ou backups pessoais.

## Roteiro de 10–15 minutos

1. Abra o [Kanban Flow](https://weslleyanjos03-png.github.io/kanban-flow/). Explique que os dados ficam somente no navegador.
2. Crie uma tarefa **fictícia** em «Primeiro contato».
3. Mova a tarefa para «Proposta» usando o seletor de etapa.
4. Edite o título e marque a tarefa como concluída.
5. Encontre a tarefa usando a busca; teste «Ocultar concluídas» e o filtro de categoria.
6. Exporte o backup JSON, sem compartilhar dados de terceiros.
7. Se desejar, importe somente esse backup de teste; confirme que o conteúdo retorna.
8. Diga qual ação foi mais confusa e qual melhoria faria primeiro.

**Não execute «Limpar quadro» com informações importantes.** Antes de importar arquivos, exporte o que deseja preservar. Os backups não são criptografados.

## Critérios para avançar

- Não pode haver **perda silenciosa de dados** ao criar, editar, mover ou importar tarefas.
- Todos devem conseguir criar e movimentar uma tarefa fictícia sem ajuda externa.
- Pelo menos 80% dos testadores devem conseguir concluir exportação e recuperação do backup após uma explicação breve.
- Erros que impeçam o uso no Android, iOS ou desktop devem ser corrigidos antes do lançamento v1.1.0.
- Feedback coletado deve virar uma [issue](https://github.com/weslleyanjos03-png/kanban-flow/issues) com reprodução ou sugestão clara.
